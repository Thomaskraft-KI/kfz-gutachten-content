# Kfz-Gutachten Content-Paket

Dieses private Repository enthält die bisher erstellten Website-Artikel und Titelbilder für UnfallhilfeNord24. Der Inhalt ist für die weitere Bearbeitung in einem anderen Manus-Account vorbereitet.

Die Markdown-Dateien sind direkt websitefähig aufgebaut: ohne Frontmatter, ohne unfertige Platzhalter und ohne interne Linkmarker. Sie enthalten SEO-orientierte Überschriften, Tabellen, FAQs, Quellenangaben und rechtliche Hinweise.

## Bilder

Zu jedem Artikel gibt es ein eigenes fotorealistisches Querformat-Titelbild im Ordner `bilder/`. Die Bilder sind keine Grafiken oder Illustrationen. Das originale Logo liegt zusätzlich als `unfallhilfeNord24-logo-original.png` im Repository und dient bei weiteren Bildproduktionen als Referenz.

Die Bildreferenzen in den Artikeln müssen beim Einfügen in ein CMS gegebenenfalls an den dortigen Medienpfad angepasst werden.

## Anforderungen für neue Inhalte

Erstelle künftig neue, eigenständige deutschsprachige SEO-Artikel zum Themenbereich Kfz-Gutachten. Vermeide Wiederholungen der bereits behandelten Themen. Wähle jeweils ein Unterthema mit klarer Suchintention und recherchiere aktuelle, belastbare Quellen.

Jeder neue Beitrag soll als sauberes Markdown ohne Frontmatter, unfertige Platzhalter oder interne Linkmarker geliefert werden. Ergänze sinnvolle Tabellen, einen FAQ-Bereich, Referenzlinks im Markdown-Format sowie einen klaren rechtlichen Hinweis. Rechtlich sensible Aussagen sind vorsichtig und nicht als individuelle Rechtsberatung zu formulieren.

Erstelle außerdem zu jedem Artikel ein neues fotorealistisches Titelbild im Querformat. Verwende das originale `unfallhilfeNord24-logo-original.png` unverändert als realistischen Aufdruck auf der Arbeitskleidung einer sachverständigen Person. Keine Grafik, keine Illustration, keine zusätzlichen Logos, keine Markenfahrzeuge und kein Wasserzeichen.

## Regelmäßiger Ablauf

Für die bisherige Sitzung wurde eine wiederkehrende Erstellung alle zwei Tage um 20:00 Uhr in der Zeitzone Europe/Berlin eingerichtet. Die Ausgabe erfolgt zunächst zur Prüfung; eine automatische Veröffentlichung auf einer externen Website ist nicht aktiviert.

## Übergabe an einen anderen Manus-Account

1. Dieses Repository im neuen Account klonen oder die Dateien aus GitHub importieren.
2. Das originale Logo aus `unfallhilfeNord24-logo-original.png` bei Bildproduktionen als Referenz verwenden.

5. Vor der Veröffentlichung Bildpfade, Quellenlinks, rechtliche Hinweise und SEO-Metadaten im jeweiligen CMS prüfen.
